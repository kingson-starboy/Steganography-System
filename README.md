# Happy Birthday Sri Shananmathi ✨

A luxurious, interactive birthday wishing website celebrating **Sri Shananmathi**, born on **21 November 2007**.

## 🌟 Highlights
- **Luxurious Theme**: Dark purple, pink, violet, and shimmering gold palette with glassmorphism and glowing effects.
- **Automatic Presentation Mode**: Automatically transitions through all pages every 9 seconds with live countdown progress, pause, resume, and skip controls.
- **6 Themed Sections / Standalone Pages**:
  - **Home**: Birthday greeting, DOB badge (21 Nov 2007), interactive candle-blowing cake, balloons, flowers & gift box.
  - **Wishes**: 6 animated wish cards for happiness, success, dreams, health, blessings, and radiance.
  - **Gallery**: Birthday cake, velvet roses, party balloons, twilight sunset, celebration toast, and a high-resolution lightbox modal.
  - **Memories**: Polaroid-style photo frames with gold tape, gentle tilt, and cursive reflections.
  - **About**: Profile card highlighting milestones, Scorpio zodiac traits, and personal birthday tribute.
  - **Surprise**: Animated 3D gift box with lid opening, confetti cannons, fanfare, and Royal Birthday Proclamation certificate.
- **Audio Experience**: Crystal music-box synthesizer (Web Audio API) playing a gentle rendition of *Happy Birthday to You* (starts only upon user interaction).
- **Extra Effects**: Floating canvas particles (stars, hearts, sparkles), interactive candle blowing, and celebratory confetti cannons.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

## 🚀 How to Run Locally
Simply open `index.html` in any modern web browser. No web server or external dependencies required!
